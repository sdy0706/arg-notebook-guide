# ARG Notebook の使い方

ARG Notebook は、ARG(代替現実ゲーム)の謎を調べるときに使う Chrome 拡張機能です。調べているページの上に、見つけたページ・キーワード・メモをまとめておく「調査用のノート」を重ねて表示します。

```figure
images/overview@2x.png
調べているページの上に「探索ログ」(左)と「収集ボックス」(中央)、「ツールボックス」が重なって表示されます
```

## できること

- **探索ログ**:見つけたページを、ページ番号付きで一覧にしておけます。何ページ中何ページ見つけたかも、ひと目で分かります。
- **収集ボックス**:気になったキーワードや、パスワード・座標などのメモをためておけます。メモは押すだけでコピーできます。
- **ツールボックス**:保存した画像や資料の一覧(ファイル)、文字化けを元に戻す「文字化け変換」、「モールス信号」の読み書きが、ページを離れずに使えます。
- **管理画面**:ARG ごとに「調査」を分けて管理できます。いくつもの ARG を同時に調べていても、データは混ざりません。

```note
保存したデータは、すべてお使いのブラウザの中だけに保存されます。外部のサーバーには送られません。
```
