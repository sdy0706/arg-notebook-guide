## 最初の調査を始める

ARG Notebook では、1 つの ARG を 1 つの「調査」として管理します。調査には、2 種類のページを登録します。

| ページ | どんなページか | パネル |
|---|---|---|
| **導入ページ** | 調査の案内や入口が書かれたページ(公式サイトの告知など) | 表示しない |
| **調査ページ** | 実際に謎を調べていくページ。ドメイン(サイト)ごとに登録する | 表示する |

### 1. 導入ページから調査を始める

```steps
ARG の導入ページ(案内が書かれたページ)を開く
ページの上で右クリックし、「ARG Notebook: このページから調査を始める」を選ぶ
調査の名前を入れて「作成」を押す
```

```menu
ARG Notebook: このページを保存
> ARG Notebook: このページから調査を始める
```

```figure
images/start-dialog@2x.png
「このページから調査を始める」で出る画面。導入ページの欄には、今見ているページが入っています
```

### 2. 調査ページを登録する

調査を作っただけでは、まだどのページにもパネルは出ません。調べたいページを「調査ページ」として登録します。

```steps
調べたいページを開く
ページの上で右クリックし、「ARG Notebook: このページを調査ページに追加 → (調査の名前)」を選ぶ
そのページに、すぐに探索ログと収集ボックスが表示される
```

リンクを右クリックして「ARG Notebook: リンク先を調査ページに追加 → (調査の名前)」を選ぶと、リンク先のサイトを開かずに登録できます。

```tip
調査ページは**ドメイン(サイト)ごと**に登録されます。一度登録すれば、同じサイトのどのページを開いてもパネルが表示されます。ARG が複数のサイトにまたがっているときは、サイトごとに追加してください。
```

```note
導入ページには、そのサイトを調査ページとして登録していても、パネルは表示されません。調査中の導入ページは、管理画面のホーム画面にある「導入ページ」からいつでも開けます。
```
