## 最初の調査を始める

ARG Notebook では、1 つの ARG を 1 つの「調査」として管理します。調査には、2 種類のページを登録します。

| ページ | どんなページか | パネル |
|---|---|---|
| **導入ページ** | 調査の案内や入口が書かれたページ(公式サイトの告知など) | 表示しない |
| **調査ページ** | 実際に謎を調べていくページ。ドメイン(サイト)全体か、URL の範囲で登録する | 表示する |

### 1. 導入ページから調査を始める

```steps
ARG の導入ページ(案内が書かれたページ)を開く
ページの上で右クリックし、「ARG Notebook: このページから調査を始める」を選ぶ
調査の名前を入れて「作成」を押す
```

```menu
ARG Notebook: このページを保存
> ARG Notebook: このページから調査を始める
```

```figure
images/start-dialog@2x.png
「このページから調査を始める」で出る画面。導入ページの欄には、今見ているページが入っています
```

### 2. 調査ページを登録する

調査を作っただけでは、まだどのページにもパネルは出ません。調べたいページを「調査ページ」として登録します。

```steps
調べたいページを開く
ページの上で右クリックし、「ARG Notebook: このページを調査ページに追加 → (調査の名前)」を選ぶ
そのページに、すぐに探索ログと収集ボックスが表示される
```

リンクを右クリックして「ARG Notebook: リンク先を調査ページに追加 → (調査の名前)」を選ぶと、リンク先のページを開かずに登録できます。

```tip
ふつうのサイトは**ドメイン(サイト)全体**で登録されます。一度登録すれば、同じサイトのどのページを開いてもパネルが表示されます。ARG が複数のサイトにまたがっているときは、サイトごとに追加してください。
```

```note
導入ページには、そのサイトを調査ページとして登録していても、パネルは表示されません。調査中の導入ページは、管理画面のホーム画面にある「導入ページ」からいつでも開けます。
```

### 3. YouTube や X のページを登録する

調査の途中で YouTube の動画や X(Twitter)のアカウントに誘導されることがあります。こうしたサイトをドメイン全体で登録すると、調査と関係なく YouTube や X を見ているときにもパネルが出てしまいます。そこで、調査ページは「**URL の範囲**」でも登録できます。URL の範囲で登録すると、その URL で始まるページだけにパネルが表示されます。

YouTube・X・Instagram・TikTok では、右クリックの「このページを調査ページに追加」「リンク先を調査ページに追加」を選ぶと、**自動で URL の範囲として登録**されます。

| 開いているページ | 登録される範囲 |
|---|---|
| X のアカウント・投稿 | `x.com/アカウント名`(そのアカウントのページすべて) |
| YouTube のチャンネル | `youtube.com/@チャンネル名` |
| YouTube の動画 | `youtube.com/watch?v=動画ID`(その動画だけ) |
| Instagram・TikTok | アカウント(`instagram.com/名前`、`tiktok.com/@名前`)、または投稿 |

```note
YouTube の動画のページは、チャンネルの範囲には入りません。チャンネルと動画の両方を調べるときは、それぞれ登録してください。
```

範囲を自分で決めたいときは、管理画面の調査の詳細画面で「＋ ドメインを追加」を押し、「登録する範囲」で「URL の範囲」を選んで、`x.com/アカウント名` のように入力します(くわしくは「管理画面」)。

```tip
YouTube や X は、ページを読み直さずに画面だけが切り替わります。範囲の外のページに移るとパネルは自動で隠れ、範囲の中に戻るとまた表示されます。
```
