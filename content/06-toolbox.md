## ツールボックス

収集ボックスの右隣の「ツールボックス」を押すと、ツールの一覧が開きます。選んだツールは、ページの上に小さなウィンドウで開きます。

```figure
images/toolbox@2x.png
ツールの一覧
```

ツールのウィンドウは、ラベルをドラッグして動かせます。ラベルを押すと畳めて、✕ で閉じます。開いたままほかのページへ移動すると、移動先でも同じツールが開きます。

### ファイル

右クリックで保存した画像や資料の一覧です。

```figure
images/tool-files@2x.png
ファイルの一覧(サムネイル表示)。右上でリスト表示に切り替えられます
```

- 画像の上で右クリックして「画像をファイル一覧に保存」を選ぶと保存されます。
- PDF などの資料へのリンクを右クリックして「リンク先をファイル一覧に保存」を選ぶと保存されます。
- ファイルを押すと、今のページの上に大きく表示されます。画像は拡大・回転ができ、PDF と PowerPoint はページをめくりながら読めます。
- カーソルを当てると、名前の変更と削除のボタンが出ます。

```figure
images/lightbox@2x.png
保存した画像を開いたところ。下のボタンで拡大・縮小・回転ができます
```

```tip
ファイルを開いたまま、文字化け変換やモールス信号のウィンドウを使えます。画像に書かれた暗号を見ながら解きたいときに便利です。
```

### 文字化け変換

文字化けした文字列を貼り付けると、元の文字に戻した候補を、読めそうな順に表示します。

```figure
images/tool-mojibake@2x.png
「縺薙ｓ縺ｫ縺｡縺ｯ」を貼り付けると「こんにちは」が出ます
```

- いちばん読めそうな候補には「有力」が付きます。
- 2 回文字化けしているときは、結果の「入力に使う」でもう一度変換してください。
- 「�」が混じった文字化けも、前後から推定して補います。ただし推定なので、正しいとは限りません。

### モールス信号

モールス信号を文字に、文字をモールス信号に変換します。

```figure
images/tool-morse@2x.png
「・・・ －－－ ・・・」を入れると、欧文(SOS)と和文(ラレラ)の両方の読み方が出ます
```

- **モールス → 文字**:同じ符号でも欧文と和文で意味が違うため、両方の読み方を表示します。入力欄の下のボタン(・ / － / 空白 / 「/」)でも入力できます。文字の区切りは空白、単語の区切りは「/」です。
- **文字 → モールス**:ひらがな・カタカナは和文、英数字は欧文のモールス信号になります。
- 「再生」で、モールス信号を音で聞けます。

```note
ツールはすべて拡張機能の中だけで動きます。入力した文字が外部に送られることはありません。
```
