## 管理画面

ツールバーの ARG Notebook のボタンを押すと、画面の右側に管理画面が開きます。調査の切り替えや、調査ごとの設定をここで行います。

### ホーム画面

```figure
images/manager-home@2x.png
ホーム画面
```

- 上の「調査中:」で、今調べている調査を切り替えます。ページの保存やキーワードは、ここで選んでいる調査に入ります。
- **導入ページ**:調査中の導入ページを新しいタブで開きます。
- **調査一覧**:調査の一覧と、それぞれの設定を開きます。
- **設定**:パネルの位置や開き方などを変えます。

```tip
登録したサイトを開くと、そのサイトを登録している調査に自動で切り替わります。いくつもの ARG を並行して調べていても、選び直す必要はほとんどありません。
```

### 調査一覧

```figure
images/manager-list@2x.png
調査一覧。今選んでいる調査には「選択中」が付きます
```

「＋ あたらしい調査をはじめる」からも調査を作れます。調査のカードを押すと、その調査の詳細画面が開きます。

### 調査の詳細

```figure
images/manager-detail@2x.png
調査の詳細画面
```

| 項目 | 内容 |
|---|---|
| 調査案件名 | 調査の名前 |
| 導入ページ | 調査の案内が書かれたページの URL。「開く」で新しいタブに開きます |
| 調査ページのドメイン | 登録したサイトの一覧。「＋ ドメインを追加」で追加し、編集ボタンで表示名と全部のページ数を設定します |
| 合計進捗 | すべてのサイトの「見つけたページ数 / 全部のページ数」の合計 |
| 書き出し | その調査のページ、またはキーワード・メモを、ファイル(JSON)に書き出します |
| この案件を削除 | 調査と、保存したページ・キーワード・メモ・ファイルをすべて削除します |

```tip
「全部のページ数」を設定しておくと、探索ログのラベルに「9 / 18」のような進み具合が出て、グリッド表示にまだ見つけていない番号のマスも並びます。
```

### 設定

```figure
images/manager-settings@2x.png
設定画面
```

| 設定 | 内容 |
|---|---|
| 探索ログの位置 / 収集ボックスの位置 | パネルを最初に表示する位置 |
| 探索ログの開き方 / 収集ボックスの開き方 | 「クリックで開閉」か、カーソルを当てると開く「マウスオーバー」 |
| 探索ログの並び替えボタン | カードのつまみを表示するかどうか(非表示にすると並び替えはできません) |
| ページ上のパネルの位置 | 「最初の位置に戻す」で、ドラッグして動かしたパネルの位置をすべてのサイトで元に戻します |
| 右クリックメニュー | 調査ページで、ARG Notebook 独自のメニューを使うか、ブラウザ標準のメニューを使うか |
| 選択テキスト保存時に空白を除去 | 右クリックでキーワード・メモを保存するとき、文字の間の空白を取り除くかどうか |

各設定の名前の横の ⓘ にカーソルを当てると、くわしい説明が出ます。
