## 右クリックメニュー

調査ページでは、右クリックすると ARG Notebook のメニューが出ます。右クリックした場所によって、出てくる項目が変わります。

```figure
images/menu@2x.png
文字を選んで右クリックしたところ
```

| 項目 | 出てくる場所 | すること |
|---|---|---|
| 選択中のキーワードを貼り付け | 入力欄の上(キーワードを選んでいるとき) | 選んだキーワードを、選んだ順に入力する |
| 選択テキストをキーワードとして保存 | 文字を選んでいるとき | 収集ボックスのキーワードに保存 |
| 選択テキストをメモとして保存 | 文字を選んでいるとき | 収集ボックスのメモに保存 |
| 画像をファイル一覧に保存 | 画像の上 | ツールボックスの「ファイル」に保存 |
| リンク先をファイル一覧に保存 | PDF などの資料へのリンクの上 | ツールボックスの「ファイル」に保存 |
| このページを保存 | どこでも | 探索ログに保存 |
| リンクをページとして保存 | リンクの上 | リンク先を探索ログに保存 |
| リンク先を調査ページに追加 | まだ登録していないサイトへのリンクの上 | リンク先のサイトを、調査中の調査に登録 |

```tip
いつものブラウザのメニュー(「戻る」「コピー」など)を使いたいときは、**Shift キーを押しながら右クリック**してください。設定で、ブラウザ標準のメニューに切り替えることもできます。その場合、上の項目は「ARG Notebook: 〜」としてブラウザのメニューに並びます。
```

### 調査ページではないページ

登録していないページでは、ブラウザのメニューに次の項目が並びます。

| 項目 | すること |
|---|---|
| ARG Notebook: このページから調査を始める | このページを導入ページにして、新しい調査を作る |
| ARG Notebook: このページを調査ページに追加 → (調査の名前) | このページのサイトを、選んだ調査に登録する |
| ARG Notebook: リンク先を調査ページに追加 → (調査の名前) | リンク先のサイトを、選んだ調査に登録する |
| ARG Notebook: このページを保存 | このページを探索ログに保存する |
| ARG Notebook: 選択テキストをキーワードとして保存 | 選んだ文字をキーワードに保存する |
