# プライバシーポリシー

Chrome 拡張機能「ARG Notebook」(以下「本拡張機能」)における、情報の取り扱いについて説明します。

## 保存する情報

本拡張機能は、利用者が保存の操作をしたときに、次の情報を保存します。

- 探索ログに保存したページの URL・タイトル・ページ番号・メモ・タグ
- 収集ボックスに保存したキーワードとメモ
- ファイルに保存した画像や資料の URL と名前
- 調査の名前、導入ページの URL、調査ページのドメイン
- パネルの位置や開き方などの設定

## 保存する場所

これらの情報は、すべて利用者のブラウザの中(Chrome の拡張機能用の保存領域)にだけ保存します。開発者のサーバーやそのほかの外部のサーバーに送ることはありません。

## 外部への送信

本拡張機能は、利用者の情報を外部に送信しません。また、利用状況の計測や広告のための情報の収集も行いません。

ファイルに保存した画像や資料を開くときは、表示のために、その画像や資料がある元のサイトからデータを読み込みます。

## 権限について

| 権限 | 使い道 |
|---|---|
| ストレージ | 上記の情報をブラウザの中に保存するため |
| 右クリックメニュー | 右クリックメニューに保存などの項目を追加するため |
| 表示中のタブ・スクリプトの実行 | 調査ページにパネルを表示し、新しい調査を作る画面を出すため |
| サイドパネル | 管理画面をサイドパネルに表示するため |
| すべてのサイトへのアクセス | 利用者が登録した調査ページにパネルを表示するため、また保存したファイル(PDF・PowerPoint)を読み込んで表示するため |

## 情報の削除

保存した情報は、管理画面から調査ごとに削除できます。本拡張機能を Chrome から削除すると、保存した情報もすべて削除されます。
